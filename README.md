# Transaction-Analytics-Visualization
Large-scale credit card transaction analysis dashboard built using Python, Pandas, and Matplotlib.

## Overview
This project performs large-scale financial transaction analysis using Python and data science libraries.
The system cleans, processes, analyzes, and visualizes credit card transaction data to generate meaningful business insights and transaction trends.
## Features
- Data cleaning and preprocessing
- Duplicate handling
- Missing value management
- Transaction statistics generation
- Monthly transaction trend analysis
- Transaction type distribution analysis
- Merchant state analysis
- Automated dashboard generation
- Report generation using Python
  
## Technologies Used
- Python
- Pandas
- Matplotlib
